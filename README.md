# 开心消消乐棋盘读取插件

DSH 工具 `xxl_board` 通过已授权的 ADB 和 `su` 截取屏幕。每次调用都会重新定位格线。开局动画结束后调用即可取得本关坐标，无需填写行列数。

```sh
npm ci
npm test
npm pack
```

## 返回值

保留 `ok`、`grid`、`legend`、`rows`、`cols`、`x`、`y`、`cellSize` 和 `captureMs`。新增按行排列的 `cells`，每条包含从 1 开始的 `row`、`col`、格心屏幕像素坐标 `x`、`y`、`code` 和 `status`。文本输出在网格后列出坐标。坐标对应 ADB 截图的像素尺寸。棋盘定位失败时返回 `{ ok: false, reason }`。

| 字符 | 含义 |
| --- | --- |
| `.` | 有格子，但当前没有棋子 |
| `~` | 与背景空洞参考图匹配 |
| `#`、`I`、`E` | 饼干盒、冰块、蛋形障碍。饼干盒按占用的每格输出 |
| `?` | 帧间有变化、分类太接近，或证据不足 |
| `!` | 稳定、明显不同于模板，且未能分配临时代码 |
| `a–z`、`0–9` | 已记录的临时视觉类型 |
| 大写字母 | 已校准类型 |

## 配置与校准

- 默认取两帧，间隔 `frameDelayMs: 75`；同一位置外观变化时输出 `?`。设置 `frames: 1` 可降低延迟，此时不学习新类型。已有 ADB 参数 `adb`、`serial`、`mode` 仍可用。用 `node capture.cjs [serial]` 比较设备上的 pipe 和 pull。
- 自定义 `calibration` 或环境变量 `XXL_CALIBRATION` 指向 version 1 JSON。保留 `screen` 和 `board` 作为屏幕基准、格距和格线相位提示。默认在屏高 22%–87% 搜索，可配置 `searchY`。建议从截图裁切完整单格，加入 `references`，例如 `{"file":"refs/hole.png","code":"~","label":"空洞"}`。背景或主题变化较大时可以为同一代码添加多张参考图。饼干盒整块裁图使用 `span: 2`，识别时要求完整的 2×2 占位。单格饼干盒可提供单独的参考图。其他障碍参考可加 `"kind": "obstacle"`，以标记类型并排除其作为动物锚点。
- 默认样本目录为用户目录下的 `.xxl-board/samples`。可用 `learnedDir` 或 `XXL_LEARNED_DIR` 改路径，`learnedDir: false` 关闭写入。样本保存颜色和空间分布特征。可修改 JSON 中的 `label`；要升级为正式动物或障碍类型，请将完整格子的 PNG 裁图加入校准文件。多种皮肤建议分开使用样本目录。进程异常退出遗留 `.write.lock` 时，确认没有进程写入后可删除该锁文件。

识别需要至少四个已校准的动物锚点，跨至少两行两列。行列范围来自能稳定识别出的格子边界。未校准的孔洞会保留为 `?`，完全缺乏可识别格子的外缘可能被裁掉。自动学习只处理两帧稳定、两侧有已知格子且颜色信号明显的视觉类型，临时代码本身无法确认动物身份。冰层与特殊障碍的判定依赖参考图。ADB 截图耗时随设备和连接变化。
